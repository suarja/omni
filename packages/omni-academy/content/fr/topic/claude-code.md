Claude Code lit les skills et plugins dans ses dossiers attendus et peut appeler des serveurs MCP locaux. Omni prépare ces conventions après validation du résumé de connexion.

Lors d’une installation manuelle, Omni observe le format Claude Code sans copier la source dans un cache privé.

[Installer une marketplace à la main](academy://tutorial/install-a-marketplace-by-hand) explique les vérifications autour d’une installation native.

## Dans Omni

Réglages et observations du projet

Utilisez `Réglages`, puis `Agents` pour connecter Claude Code. Les pastilles de skills du projet montrent les copies observées. Le menu `Plugins et vitrines` ne propose ni guide d’installation native à la main ni verdict de compatibilité.

[Installer une marketplace à la main](academy://tutorial/install-a-marketplace-by-hand) explique la frontière avec l’installation native.
