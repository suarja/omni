Un projet est une racine locale enregistrée, pas seulement un nom. Son inventaire observé donne à Omni les preuves nécessaires aux assignations, dérives et captures.

Le sélecteur de skills nomme le projet cible et permet de choisir les agents avant l’ajout.

[Ajouter un plugin à un projet](academy://tutorial/add-a-plugin-to-a-project) montre le parcours sûr.

## Dans Omni

Espace de travail et skills du projet

Ouvrez un nœud de projet dans `Espace de travail`, puis `Gérer les skills`. Les onglets sont `Skills`, `Instructions` et `Infos`. Utilisez `＋ Ajouter des skills` pour les skills de la marketplace et `Actualiser` pour relire les preuves locales.

[Ajouter un plugin à un projet](academy://tutorial/add-a-plugin-to-a-project) suit ce sélecteur.
