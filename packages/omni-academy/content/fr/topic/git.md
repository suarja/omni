Git suit les commits et l’état de travail. Omni suit le reçu de l’opération, les fichiers exacts et les preuves avant-après.

L’historique des opérations explique ce qu’Omni a écrit tandis que Git explique l’historique du projet.

[Annuler ce qu’Omni a écrit](academy://tutorial/undo-anything-omni-wrote) décrit la restauration.

## Dans Omni

Preuves du projet et historique des opérations

L’onglet `Infos` d’un projet montre les preuves Git. `Historique` conserve les opérations terminées ; ouvrez un résultat pour lire les informations Git enregistrées. `À valider` conserve les demandes en attente et les vérifications.

[Annuler ce qu’Omni a écrit](academy://tutorial/undo-anything-omni-wrote) suit le reçu.
