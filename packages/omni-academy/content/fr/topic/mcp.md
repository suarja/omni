MCP permet à un client de découvrir et d’appeler des outils via un serveur standard. Dans Omni, le serveur est local et la passerelle identifie le harness quand c’est possible.

Les lectures répondent depuis l’état observé ; les écritures demandent un consentement et produisent un reçu.

[Installer Omni pour vos agents](academy://tutorial/install-omni-for-your-agents) montre la configuration.

## Dans Omni

Réglages et preuves de connexion

Dans `Réglages`, choisissez `Connecter` pour un agent détecté mais pas connecté, puis lisez le résumé de confirmation. Après un appel réel à Omni, utilisez `Plus d'actions`, puis `Vérifier la connexion`. `À valider` conserve les demandes en attente ; `Historique` conserve les opérations terminées.

[Installer Omni pour vos agents](academy://tutorial/install-omni-for-your-agents) suit ces pages.
