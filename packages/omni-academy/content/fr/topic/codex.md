Codex lit les skills dans son format natif et peut appeler un serveur MCP local. Omni garde cette projection explicite afin de partager une source sans mélanger les fichiers incompatibles.

[Installer une marketplace à la main](academy://tutorial/install-a-marketplace-by-hand) explique les vérifications autour d’une installation native.

## Dans Omni

Réglages et observations du projet

Utilisez `Réglages`, puis `Agents` pour connecter Codex. Dans l’onglet `Skills` d’un projet, sa pastille indique une installation observée. Elle ne prouve pas que le chargeur natif a activé un plugin entier.

[Installer une marketplace à la main](academy://tutorial/install-a-marketplace-by-hand) explique le parcours manuel.
