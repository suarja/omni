Claude Code reads skills and plugins from its expected directories and can call local MCP servers. Omni prepares those conventions after you confirm the connection summary.

When a marketplace is installed by hand, Omni observes the Claude Code layout instead of copying it into a private cache.

[Install a marketplace by hand](academy://tutorial/install-a-marketplace-by-hand) explains what to check around a native installation.

## In Omni

Settings and project observations

Use `Settings`, then `Agents` to connect Claude Code. Project skill chips show observed copies. The `Plugins and storefronts` menu does not provide a native manual-install guide or a compatibility verdict.

[Install a marketplace by hand](academy://tutorial/install-a-marketplace-by-hand) explains the boundary with native installation.
