Git tracks commits and working-tree state. Omni tracks the operation receipt, the exact files, and the before-and-after evidence.

The operation history explains what Omni wrote, while Git explains the project history.

[Undo anything Omni wrote](academy://tutorial/undo-anything-omni-wrote) covers the restore boundary.

## In Omni

Project evidence and operation history

A project’s `Info` tab shows Git evidence. `Activity` holds completed operations; open a result to read the Git outcome when recorded. `Review` holds pending requests and checks.

[Undo anything Omni wrote](academy://tutorial/undo-anything-omni-wrote) follows the receipt to restore.
