MCP lets a client discover and call tools through a standard server boundary. In Omni, the server is local and the gateway identifies the calling harness when possible.

Reads can answer from observed state. Writes become explicit requests with consent and receipts.

[Install Omni for your agents](academy://tutorial/install-omni-for-your-agents) shows the setup.

## In Omni

Settings and connection evidence

In `Settings`, choose `Connect` for a detected, disconnected agent, then read the summary confirmation. After a real Omni call, use the agent’s `More actions`, then `Check connection`. `Review` holds pending requests; `Activity` holds completed operations.

[Install Omni for your agents](academy://tutorial/install-omni-for-your-agents) mirrors those pages.
