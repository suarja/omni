Codex reads skills from its native skills layout and can call a local MCP server. Omni keeps that projection explicit so Codex and Claude Code can share the same source without sharing incompatible files.

[Install a marketplace by hand](academy://tutorial/install-a-marketplace-by-hand) explains what to check around a native installation.

## In Omni

Settings and project observations

Use `Settings`, then `Agents` to connect Codex. In a project’s `Skills` tab, the Codex chip indicates an observed installation. It does not prove that a native plugin loader enabled a whole plugin.

[Install a marketplace by hand](academy://tutorial/install-a-marketplace-by-hand) explains the manual path.
