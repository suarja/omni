# Security policy

Report suspected vulnerabilities privately through this repository's GitHub Security
Advisories page. Open the Security tab and choose **Report a vulnerability**.
Do not post exploit details, credentials, personal profiles, or private project data in a
public issue. If private reporting is unavailable, wait until maintainers provide a private
reporting channel before sharing sensitive details.

Include the affected version, macOS version, reproduction steps, expected and actual behavior,
and a minimal synthetic example. Describe the potential impact and any workaround you found.
The maintainers will assess the report and coordinate disclosure through the private advisory.

Only macOS is currently supported. Development snapshots may differ from published releases;
identify the release or commit used when reporting a problem.
